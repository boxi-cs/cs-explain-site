# cs-explain-site

Public documentation, demonstrations, and learning entry point for Boxi CS explainers.

> **Status:** scaffold. The site will publish reviewed examples from `cs-explain` and `cs-scenes`.

The site is a presentation layer. It should support interactive replay where available and always provide static SVG/HTML plus a text transcript. The public site must remain buildable offline from pinned artifacts.

The site does not own the trace schema, hidden course material, or assessment logic.
